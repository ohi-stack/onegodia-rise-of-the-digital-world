# Published browser game and this repository

[Play OneGodia in the browser](https://onzara.onegodian.chatgpt.site/play). The Sites edition contains direct access to the Three.js district and 2D missions, plus browser-local inventory and game businesses. The released portal also includes a vehicle configurator and an in-game credit dashboard.

This repository retains the original browser-game source and its existing build. Features delivered in the Sites edition should be checked against that edition before marking them available in this repository. The browser credit balance and saved progress belong to the browser origin where they were created.
